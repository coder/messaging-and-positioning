## One-Line Positioning

GitHub Copilot is GitHub's AI coding assistant and agent, and it runs inside Coder workspaces from the IDE or the CLI, but Copilot cloud agent runs on GitHub-managed infrastructure, so organizations that need agent execution, orchestration, and model routing on their own infrastructure use Coder Agents instead.

## Strategic Themes and Patterns

- **Relationship.** Copilot has parts that relate to Coder differently. Copilot in the IDE and Copilot CLI are clients that run wherever a developer works, including in a Coder workspace, which is complementary ([GitHub Docs](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-in-ides), [Coder Registry](https://registry.coder.com/modules/coder-labs/copilot)). Copilot cloud agent works on tasks in a [GitHub-hosted cloud sandbox or a GitHub Actions environment](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github) and opens pull requests, which competes with Coder Agents for the background-agent decision.
- **Choice, Control, Consistency.** For cloud agent, the tradeoff is Control and Choice. Orchestration and models are GitHub-hosted, Copilot is [not currently available for GitHub Enterprise Server](https://docs.github.com/en/copilot/get-started/plans), and cloud agent [only works with repositories hosted on GitHub](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github). Coder Agents runs its agent loop in the customer's Coder deployment and connects to any supported model provider or self-hosted endpoint ([Coder Agents docs](https://coder.com/docs/@main/ai-coder/agents)). For Consistency, cloud agent environments are set with a [setup-steps workflow file](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/customize-the-agent-environment), while Coder workspaces come from Terraform templates shared by developers and agents.
- **Lock-in risk.** Standardizing background agents on Copilot cloud agent ties agent execution, session history, and AI spend to GitHub as the source host and billing platform. An organization that later moves repositories off GitHub, needs GitHub Enterprise Server, or must run disconnected would need a different agent platform. Coder works with [GitHub, GitLab, Bitbucket, and Azure DevOps](../products/coder-workspaces/message-house.md).
- **Build versus buy.** Teams that want Copilot's agents with self-hosted execution often build it themselves on self-hosted Actions runners, which GitHub supports [only in the Actions environment, with the integrated firewall disabled](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/customize-the-agent-environment). Coder provides governed execution through Terraform-provisioned workspaces with network policy set in each template. See [Why Coder](../company/why-coder.md).
- **Where Copilot is sufficient on its own.** GitHub Enterprise Cloud organizations that accept GitHub-hosted orchestration and execution get completions, chat, agents, and code review under one seat. See "When Copilot Alone Is Enough" below.
- **How they work together.** Coder publishes a [Copilot CLI module](https://registry.coder.com/modules/coder-labs/copilot) that installs Copilot CLI in a workspace ([Coder Blog](https://coder.com/blog/github-copilot-cli-now-runs-natively-in-coder-workspaces)). Developers can also use Copilot in VS Code connected to a workspace, since VS Code agents can run [on a remote machine over SSH](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-in-ides). With Coder Premium, AI Gateway brings Copilot traffic under centralized auditing through [AI Gateway Proxy](https://coder.com/docs/@main/ai-coder/ai-gateway/clients/copilot), while each user still authenticates with GitHub.

## Coder's Strengths Here

- **Self-hosted agent loop.** Coder Agents runs the agent loop, chat history, and tool execution in the customer's Coder deployment ([Coder Agents docs](https://coder.com/docs/@main/ai-coder/agents)). Copilot cloud agent sessions run in [GitHub-managed sandboxes or Actions runners](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github), with orchestration on GitHub.
- **Air-gapped operation.** [All Coder features are supported in air-gapped and offline deployments](https://coder.com/docs/@main/install/airgap). For Copilot, GitHub documents only Copilot CLI's offline mode, which is fully air-gapped [only if the bring-your-own-key model provider is local](https://docs.github.com/en/copilot/how-tos/copilot-cli/set-up-copilot-cli/authenticate-copilot-cli).
- **Any Git provider.** Coder connects to GitHub, GitLab, Bitbucket, and Azure DevOps through [external authentication](https://coder.com/docs/@main/admin/external-auth). Copilot cloud agent requires GitHub-hosted repositories ([GitHub Docs](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github)).
- **Model routing from the customer's control plane.** Coder Agents connects to Anthropic, OpenAI, Google, Azure, AWS Bedrock, or any OpenAI-compatible endpoint ([Coder Agents docs](https://coder.com/docs/@main/ai-coder/agents)). Copilot's organization-level custom models are in [public preview and are served through GitHub's Copilot API](https://docs.github.com/en/copilot/concepts/models/bring-your-own-key).
- **One environment for developers and agents.** Agents work in the same Terraform-defined workspaces developers use, on any infrastructure ([Coder Workspaces message house](../products/coder-workspaces/message-house.md)). Copilot cloud sandboxes [don't support custom compute or self-hosted runners](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github).
- **Network policy set by the platform team.** Platform teams set what each workspace can reach in the template ([template network boundaries](https://coder.com/docs/@main/ai-coder/agents/platform-controls/template-optimization#configure-network-boundaries)), using network controls the customer already runs.
- **Governance across tools.** AI Gateway centralizes authentication, auditing, and cost control for Claude Code, Codex, OpenCode, and other clients alongside Copilot ([AI Governance message house](../products/coder-ai-governance/message-house.md)), so Copilot can be one of several governed tools rather than the only one.

## GitHub Copilot Overview

- **What it is.** GitHub's AI coding product, spanning inline suggestions, chat, and agent mode in [VS Code, Visual Studio, JetBrains IDEs, Eclipse, Xcode, and Neovim](https://docs.github.com/en/copilot/reference/copilot-feature-matrix), plus Copilot CLI, [generally available since February 25, 2026](https://github.blog/changelog/2026-02-25-github-copilot-cli-is-now-generally-available/), and Copilot code review.
- **Cloud agent.** Copilot cloud agent takes assigned tasks and opens pull requests. It became [generally available on September 25, 2025](https://github.blog/changelog/2025-09-25-copilot-coding-agent-is-now-generally-available/) as the Copilot coding agent. Since October 28, 2026, sessions run by default in a [GitHub-managed cloud sandbox](https://github.blog/changelog/2026-10-28-work-from-anywhere-with-a-new-connected-copilot-cloud-experience/), started from GitHub, the CLI, VS Code, Slack, or Teams.
- **Execution environments.** Cloud sandboxes are GitHub-hosted Linux environments without custom compute or self-hosted runners. The alternative Actions environment runs on GitHub-hosted or self-hosted runners, with a [59-minute session maximum](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github). Self-hosted runners must be [Ubuntu x64 or Windows 64-bit](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/customize-the-agent-environment).
- **Third-party agents.** Anthropic Claude and OpenAI Codex agents run on GitHub in [public preview](https://docs.github.com/en/copilot/concepts/agent-capabilities/about-agents/about-third-party-coding-agents).
- **Models.** Copilot offers models from Anthropic, OpenAI, Google, xAI, and others, with plan-dependent access ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)). Individual users can bring their own key in supported clients, and organization-level custom models are in [public preview](https://docs.github.com/en/copilot/concepts/models/bring-your-own-key).
- **Enterprise controls.** Business and Enterprise include policy management, [content exclusion](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/content-exclusion), and an [audit log retained for 180 days with SIEM streaming](https://docs.github.com/en/copilot/how-tos/administer-copilot/manage-for-enterprise/review-audit-logs). The cloud agent has an [integrated firewall](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-the-firewall), on by default with a recommended allowlist.
- **Target customer.** Individual developers through enterprises on GitHub, from a Free plan to Business and Enterprise seats ([GitHub plans](https://github.com/features/copilot/plans)).
- **Deployment model.** A GitHub-hosted service that clients reach over the internet or a proxy ([GitHub network settings](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/network-settings)). Copilot is available with GitHub Enterprise Cloud data residency, and is not available for GitHub Enterprise Server ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)).

## Coder Overview for This Comparison

- **Copilot in workspaces.** The [Copilot CLI module](https://registry.coder.com/modules/coder-labs/copilot) installs and configures Copilot CLI in a workspace. Developers can use Copilot in the IDEs Coder supports, such as VS Code and JetBrains ([Coder Workspaces FAQ](../products/coder-workspaces/faq.md)).
- **AI Gateway for Copilot.** Copilot doesn't support custom base URLs, so AI Gateway governs it through [AI Gateway Proxy](https://coder.com/docs/@main/ai-coder/ai-gateway/clients/copilot), using per-user GitHub tokens. AI Gateway is part of [AI Governance](https://coder.com/docs/@main/ai-coder/ai-governance), included with Premium.
- **Coder Agents.** A self-hosted agent that runs in the Coder control plane and works in Coder workspaces, with models from the providers an admin configures ([Coder Agents docs](https://coder.com/docs/@main/ai-coder/agents)).
- **Workspaces.** Terraform-provisioned environments on any cloud, on-premises, or air-gapped ([Coder Workspaces message house](../products/coder-workspaces/message-house.md)).

## Where GitHub Copilot Is Strong or Coder Has a Gap

*(This section applies to the competitive relationship with Copilot cloud agent.)*

- **Native to GitHub.** Cloud agent works from issues, pull requests, and GitHub Mobile, and pushes only to its own branch ([GitHub Docs](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/risks-and-mitigations)). Code review runs on the same platform.
- **No infrastructure to operate.** Cloud sandboxes are GitHub-hosted ([GitHub Changelog](https://github.blog/changelog/2026-10-28-work-from-anywhere-with-a-new-connected-copilot-cloud-experience/)). Coder is [self-hosted](../company/why-coder.md), so the customer runs the control plane and the compute.
- **Inline completions.** Copilot includes unlimited inline suggestions on paid plans ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)). Coder doesn't provide code completion. Developers bring an assistant such as Copilot.
- **Models bundled with the seat.** Business and Enterprise seats include pooled AI Credits for a catalog of hosted models ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)). Coder Agents needs the customer's own model provider accounts or endpoints.
- **Coder Agents can't use a Copilot subscription.** Copilot authenticates with a per-request token that only an official Copilot client can mint, so the Coder Agents harness [can't use a Copilot provider](https://coder.com/docs/@main/ai-coder/agents/models). Copilot still works in workspaces through its own clients.

## Known Limitations in GitHub Copilot's Approach

- **GitHub-hosted repositories only for cloud agent (as of 2026-10-29).** GitHub states that Copilot on GitHub [only works with repositories hosted on GitHub](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github).
- **Not available for GitHub Enterprise Server (as of 2026-10-29).** Copilot is [not currently available for GitHub Enterprise Server](https://docs.github.com/en/copilot/get-started/plans).
- **Limited self-hosted execution (as of 2026-10-29).** Cloud sandboxes don't support self-hosted runners. Self-hosted runners work only in the Actions environment, where the integrated firewall [isn't compatible with self-hosted runners](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/customize-the-agent-environment) and must be disabled, and sessions are capped at [59 minutes](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github).
- **Firewall scope (as of 2026-10-29).** The cloud agent firewall applies only to processes the agent starts through its Bash tool, not to MCP servers or setup steps, and GitHub notes that [sophisticated attacks may bypass it](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-the-firewall).
- **Content exclusion gaps (as of 2026-10-29).** Content exclusion doesn't cover [Edit and Agent modes of Copilot Chat in VS Code](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/content-exclusion) and other editors, and doesn't apply to repositories on remote filesystems.
- **No air-gapped service (as of 2026-10-29).** Copilot is GitHub-hosted. The only documented offline path is Copilot CLI with a [local bring-your-own-key model](https://docs.github.com/en/copilot/how-tos/copilot-cli/set-up-copilot-cli/authenticate-copilot-cli).

## Common Questions

- **Can our developers keep using Copilot in Coder workspaces?** Yes. Copilot CLI installs through the [Copilot CLI module](https://registry.coder.com/modules/coder-labs/copilot), and VS Code agents can run [on a remote machine over SSH](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-in-ides), which is how VS Code desktop connects to a workspace ([Coder Workspaces FAQ](../products/coder-workspaces/faq.md)).
- **Can Coder audit and govern Copilot usage?** Yes, with Premium. AI Gateway governs Copilot through [AI Gateway Proxy](https://coder.com/docs/@main/ai-coder/ai-gateway/clients/copilot). Users still sign in to GitHub, because Copilot uses per-user tokens tied to GitHub accounts.
- **Can Coder Agents use our Copilot subscription for models?** No. Copilot's per-request token can only be minted by an official Copilot client, so Coder Agents [can't use a Copilot provider](https://coder.com/docs/@main/ai-coder/agents/models). Coder Agents uses providers such as Anthropic, OpenAI, Google, Azure, AWS Bedrock, or OpenAI-compatible endpoints ([Coder Agents docs](https://coder.com/docs/@main/ai-coder/agents)).
- **How does Copilot cloud agent differ from Coder Agents?** The difference is where it runs. Copilot cloud agent runs in [GitHub-managed sandboxes or Actions runners](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github) with orchestration on GitHub. Coder Agents runs in the customer's Coder deployment, on its own network, including air-gapped ([Coder Agents docs](https://coder.com/docs/@main/ai-coder/agents), [Coder Docs](https://coder.com/docs/@main/install/airgap)). See also the [Coder Agents FAQ](../products/coder-agents/faq.md#16-competitive-landscape-vs-code-agents-and-github-copilot).
- **We use GitHub Enterprise Server or GitLab. Does Copilot work for us?** Copilot is [not currently available for GitHub Enterprise Server](https://docs.github.com/en/copilot/get-started/plans), and cloud agent [only works with GitHub-hosted repositories](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github). Coder works with [GitHub, GitLab, Bitbucket, and Azure DevOps](https://coder.com/docs/@main/admin/external-auth).
- **Do we have to choose between Copilot and Coder?** No. Most teams use Copilot as a client inside Coder workspaces. The choice is only between Copilot cloud agent and Coder Agents for where background agents run, and teams can use both.
- **Which is cheaper?** It depends on usage. Copilot charges per seat with included AI Credits and metered overage. With Coder, the customer pays its own model providers and compute, plus a Coder Premium license if needed. See Pricing and Packaging below.

## When GitHub Copilot Alone Is Enough

- **GitHub Enterprise Cloud organizations without self-hosting requirements.** Teams whose code is on GitHub and that accept [GitHub-hosted agent execution](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github) get completions, chat, agents, and code review in one product.
- **Individual developers and small teams.** Developers who want an assistant in their IDE, with [Free, Pro, and Pro+ plans](https://github.com/features/copilot/plans), and no platform team.
- **Organizations without platform engineering capacity.** Teams that don't want to operate infrastructure or maintain Terraform templates.

## Pricing and Packaging

- **Copilot for organizations.** Copilot Business is $19 per granted seat per month with 1,900 AI Credits per user, and Copilot Enterprise is $39 per seat per month with 3,900 credits per user. Credits are pooled, and overage is $0.01 per credit at per-token model rates ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)). Inline suggestions don't consume credits.
- **Copilot access.** Since October 28, 2026, GitHub Enterprise Cloud customers can add Copilot access with [no included credits, so usage is metered from first use](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot/).
- **Copilot for individuals.** Free, Pro at $10 per month, Pro+ at $39 per month, and Max at $100 per month, with different credit allotments ([GitHub plans](https://github.com/features/copilot/plans)).
- **Cloud agent compute.** Cloud sandbox compute draws from the GitHub Actions entitlement ([GitHub Changelog](https://github.blog/changelog/2026-10-28-work-from-anywhere-with-a-new-connected-copilot-cloud-experience/)).
- **Coder.** Coder Community Edition is free and open source. Coder Premium pricing is not public and is available by quote, and AI Governance, including AI Gateway, is [included with Premium](https://coder.com/docs/@main/ai-coder/ai-governance). See [coder.com/pricing](https://coder.com/pricing) and [Packaging](../company/packaging.md). Model usage and compute are billed by the customer's own providers.
