## One-Line Positioning

GitHub Copilot is GitHub's AI coding assistant and agent, and it runs inside Coder workspaces from the IDE or the CLI, but Copilot cloud agent is orchestrated on GitHub and runs by default on GitHub-managed infrastructure, so organizations that need agent orchestration, execution, and model routing on their own infrastructure use Coder Agents instead.

## Strategic Themes and Patterns

- **Relationship.** Copilot has parts that relate to Coder differently. Copilot in the IDE and Copilot CLI are clients that run wherever a developer works, including in a Coder workspace, which is complementary ([GitHub Docs](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-in-ides), [Coder Registry](https://registry.coder.com/modules/coder-labs/copilot)). Copilot cloud agent works on tasks in a [GitHub-hosted cloud sandbox, a GitHub Actions environment, or a registered custom environment](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github) and opens pull requests, which competes with Coder Agents for the background-agent decision.
- **Choice, Control, Consistency.** For cloud agent, the tradeoff is Control and Choice. Sessions are orchestrated on GitHub and models are served through GitHub's Copilot service, Copilot is [not currently available for GitHub Enterprise Server](https://docs.github.com/en/copilot/get-started/plans), and cloud agent [only works with repositories hosted on GitHub](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github). Coder Agents runs its agent loop in the customer's Coder deployment and connects to any supported model provider or self-hosted endpoint ([Coder Agents docs](https://coder.com/docs/ai-coder/agents)). For Consistency, Actions-based sessions are configured with a [setup-steps workflow file](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/customize-the-agent-environment), which doesn't apply to the default cloud sandbox, while Coder workspaces come from Terraform templates shared by developers and agents.
- **Lock-in risk.** Standardizing background agents on Copilot cloud agent ties agent orchestration, session history, and AI spend to GitHub as the source host and billing platform. An organization that later moves repositories off GitHub, needs GitHub Enterprise Server, or must run disconnected would need a different agent platform. Coder works with [GitHub, GitLab, Bitbucket, and Azure DevOps](../products/coder-workspaces/message-house.md).
- **Build versus buy.** Teams that want Copilot's agents to execute on their own infrastructure can use self-hosted Actions runners, which GitHub supports [only in the Actions environment, with the integrated firewall disabled](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/customize-the-agent-environment), or register their own Linux machine as a [custom environment](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/create-a-custom-environment), which requires a prerelease Copilot CLI and access to custom environments. Either way, the customer operates the host while orchestration stays on GitHub. Coder provides governed execution through Terraform-provisioned workspaces with network policy set in each template. See [Why Coder](../company/why-coder.md).
- **Where Copilot is sufficient on its own.** GitHub Enterprise Cloud organizations that accept GitHub-hosted orchestration and execution get completions, chat, agents, and code review in one product. See "When GitHub Copilot Alone Is Enough" below.
- **How they work together.** Coder publishes a [Copilot CLI module](https://registry.coder.com/modules/coder-labs/copilot) that installs Copilot CLI in a workspace ([Coder Blog](https://coder.com/blog/github-copilot-cli-now-runs-natively-in-coder-workspaces)). Developers can also use Copilot in VS Code connected to a workspace, where the [Copilot extension runs inside the workspace](https://coder.com/docs/ai-coder/ai-gateway/clients/copilot#coder-remote-extension). With Coder Premium, AI Gateway audits Copilot's model requests from clients configured to use [AI Gateway Proxy](https://coder.com/docs/ai-coder/ai-gateway/clients/copilot), while each user still authenticates with GitHub.

## Coder's Strengths Here

- **Self-hosted agent loop.** Coder Agents runs the agent loop, chat history, and tool execution in the customer's Coder deployment ([Coder Agents docs](https://coder.com/docs/ai-coder/agents)). Copilot cloud agent sessions are orchestrated on GitHub and run by default in [GitHub-managed cloud sandboxes, with Actions runners or a registered custom environment as alternatives](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github).
- **Air-gapped operation.** [All Coder features are supported in air-gapped and offline deployments](https://coder.com/docs/install/prepare/airgap), and Coder Agents can use [self-hosted models through an OpenAI-compatible endpoint](https://coder.com/docs/ai-coder/agents/models). Copilot is a GitHub-hosted service. GitHub's offline options are client-side, such as Copilot CLI offline mode, which is fully air-gapped [only if the bring-your-own-key model provider is local](https://docs.github.com/en/copilot/how-tos/copilot-cli/set-up-copilot-cli/authenticate-copilot-cli).
- **Any Git provider.** Coder connects to GitHub, GitLab, Bitbucket, and Azure DevOps through [external authentication](https://coder.com/docs/admin/external-auth). Copilot cloud agent requires GitHub-hosted repositories ([GitHub Docs](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github)).
- **Model routing from the customer's control plane.** Coder Agents connects to Anthropic, OpenAI, Google, Azure, AWS Bedrock, or any OpenAI-compatible endpoint ([Coder Agents docs](https://coder.com/docs/ai-coder/agents)). Copilot's enterprise- and organization-level custom models are in [public preview and are served through GitHub's Copilot API](https://docs.github.com/en/copilot/concepts/models/bring-your-own-key). User-configured keys go directly to the provider but are set up per user in each client.
- **One environment for developers and agents.** Agents work in the same Terraform-defined workspaces developers use, on any infrastructure ([Coder Workspaces message house](../products/coder-workspaces/message-house.md)). Copilot cloud sandboxes [don't support custom compute or self-hosted runners](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github).
- **Network policy set by the platform team.** Platform teams set what each workspace can reach in the template ([template network boundaries](https://coder.com/docs/ai-coder/agents/platform-controls/template-optimization#configure-network-boundaries)), using network controls the customer already runs.
- **Governance across tools.** AI Gateway centralizes authentication, auditing, and cost control for [Claude Code, Codex, OpenCode, and other clients](https://coder.com/docs/ai-coder/ai-gateway/clients) ([AI Governance message house](../products/coder-ai-governance/message-house.md)) and audits Copilot through AI Gateway Proxy, so Copilot can be one of several governed tools rather than the only one.

## GitHub Copilot Overview

- **What it is.** GitHub's AI coding product, spanning inline suggestions in [VS Code, Visual Studio, JetBrains IDEs, Eclipse, Xcode, and Neovim](https://docs.github.com/en/copilot/reference/copilot-feature-matrix), with chat and agent mode in all of them except Neovim. It also includes Copilot CLI, [generally available since February 25, 2026](https://github.blog/changelog/2026-02-25-github-copilot-cli-is-now-generally-available/), and Copilot code review.
- **Cloud agent.** Copilot cloud agent takes assigned tasks and opens pull requests. It became [generally available on September 25, 2025](https://github.blog/changelog/2025-09-25-copilot-coding-agent-is-now-generally-available/) as the Copilot coding agent. The newer Copilot in the cloud experience became available on paid plans on October 28, 2026. Its sessions run by default in a [GitHub-managed cloud sandbox](https://github.blog/changelog/2026-10-28-work-from-anywhere-with-a-new-connected-copilot-cloud-experience/), started from github.com, GitHub Mobile, the Copilot app, the CLI, VS Code, Slack, or Teams.
- **Execution environments.** Cloud sandboxes are [GitHub-hosted Linux environments](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/about-cloud-sandboxes) without custom compute or self-hosted runners. The Actions environment runs on GitHub-hosted or self-hosted runners, with a [59-minute session maximum](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github). Self-hosted runners must be [Ubuntu x64 or Windows 64-bit](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/customize-the-agent-environment). A [custom environment](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/create-a-custom-environment) connects sessions to a Linux machine or codespace the customer manages.
- **Third-party agents.** Anthropic Claude and OpenAI Codex agents run on GitHub in [public preview](https://docs.github.com/en/copilot/concepts/agent-capabilities/about-agents/about-third-party-coding-agents).
- **Models.** Copilot offers models from Anthropic, OpenAI, Google, xAI, and others, with plan-dependent access ([GitHub plans](https://github.com/features/copilot/plans), [GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)). Individual users can bring their own key in supported clients, and enterprise- and organization-level custom models are in [public preview](https://docs.github.com/en/copilot/concepts/models/bring-your-own-key).
- **Enterprise controls.** Business and Enterprise include policy management, [content exclusion](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/content-exclusion), and an [audit log retained for 180 days with SIEM streaming](https://docs.github.com/en/copilot/how-tos/administer-copilot/manage-for-enterprise/review-audit-logs). The cloud agent has an [integrated firewall](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-the-firewall), on by default with a recommended allowlist.
- **Target customer.** Individual developers through enterprises on GitHub, from a Free plan to Business and Enterprise seats ([GitHub plans](https://github.com/features/copilot/plans)).
- **Deployment model.** A GitHub-hosted service that clients reach over the internet or a proxy ([GitHub network settings](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/network-settings)). Copilot is available with [GitHub Enterprise Cloud data residency](https://docs.github.com/en/enterprise-cloud@latest/admin/data-residency/github-copilot-with-data-residency), where enforcing in-region processing adds 10% to AI Credits consumption, and is not available for GitHub Enterprise Server ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)).

## Coder Overview for This Comparison

- **Copilot in workspaces.** The [Copilot CLI module](https://registry.coder.com/modules/coder-labs/copilot), published in the Coder Labs namespace, installs and configures Copilot CLI in a workspace. Developers can use Copilot in the IDEs Coder supports, such as VS Code and JetBrains ([Coder Workspaces FAQ](../products/coder-workspaces/faq.md), [Coder Docs](https://coder.com/docs/ai-coder/ai-gateway/clients/copilot)).
- **AI Gateway for Copilot.** Copilot doesn't support custom base URLs but does respect proxy configurations, so AI Gateway governs it through [AI Gateway Proxy](https://coder.com/docs/ai-coder/ai-gateway/clients/copilot), using per-user GitHub tokens. AI Gateway intercepts Copilot's chat completions, responses, and messages requests and passes other Copilot routes through to the upstream ([AI Gateway reference](https://coder.com/docs/ai-coder/ai-gateway/reference)). AI Gateway is part of [AI Governance](https://coder.com/docs/ai-coder/ai-governance), included with Premium.
- **Coder Agents.** A self-hosted agent that runs in the Coder control plane and works in Coder workspaces, with models from the providers an admin configures ([Coder Agents docs](https://coder.com/docs/ai-coder/agents)).
- **Workspaces.** Terraform-provisioned environments on any cloud, on-premises, or air-gapped ([Coder Workspaces message house](../products/coder-workspaces/message-house.md)).

## Where GitHub Copilot Is Strong or Coder Has a Gap

- **Native to GitHub.** Cloud agent works from issues, pull requests, and [GitHub Mobile](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github), and pushes to a single branch, either a new `copilot/` branch or the branch of the pull request it was invoked on ([GitHub Docs](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/risks-and-mitigations)). Code review runs on the same platform.
- **No infrastructure to operate.** Cloud sandboxes are GitHub-hosted ([GitHub Changelog](https://github.blog/changelog/2026-10-28-work-from-anywhere-with-a-new-connected-copilot-cloud-experience/)). Coder is [self-hosted](../company/why-coder.md), so the customer runs the control plane and the compute.
- **Inline completions.** Copilot includes unlimited inline suggestions on paid plans ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)). Coder Agents handles tasks rather than in-editor autocomplete, which AI IDEs and assistants such as Copilot cover ([Coder Agents playbook](../products/coder-agents/playbook.md)). When VS Code uses AI Gateway through its Custom Endpoint provider, inline suggestions [still require GitHub Copilot](https://coder.com/docs/ai-coder/ai-gateway/clients).
- **Models bundled with the seat.** Business and Enterprise seats include pooled AI Credits for a catalog of hosted models ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)). Coder Agents needs the customer's own model provider accounts or endpoints.
- **Coder Agents can't use a Copilot subscription.** Coder Agents doesn't support Copilot as a model provider. Coder's docs explain that Copilot authenticates with a per-request token that only an official Copilot client can mint, so the server-side Agents harness [can't use it](https://coder.com/docs/ai-coder/agents/models). Copilot still works in workspaces through its own clients.

## Known Limitations in GitHub Copilot's Approach

- **GitHub-hosted repositories only for cloud agent (as of 2026-10-29).** GitHub states that Copilot on GitHub [only works with repositories hosted on GitHub](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github).
- **Not available for GitHub Enterprise Server (as of 2026-10-29).** Copilot is [not currently available for GitHub Enterprise Server](https://docs.github.com/en/copilot/get-started/plans).
- **Conditions on self-hosted execution (as of 2026-10-29).** Cloud sandboxes don't support self-hosted runners. Self-hosted runners work only in the Actions environment, where the integrated firewall [isn't compatible with self-hosted runners](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/customize-the-agent-environment) and must be disabled, and sessions are capped at [59 minutes](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github). Custom environments run on a customer-managed Linux machine or codespace, require [access to custom environments](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/create-a-custom-environment), and, on a Linux machine, require a prerelease Copilot CLI. Orchestration stays on GitHub in every case.
- **Firewall scope (as of 2026-10-29).** The cloud agent firewall applies only to processes the agent starts through its Bash tool, not to MCP servers or setup steps, and GitHub notes that [sophisticated attacks may bypass it](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-the-firewall).
- **Content exclusion gaps (as of 2026-10-29).** Content exclusion [doesn't cover Edit and Agent modes in VS Code, or chat and agent in Xcode and Eclipse](https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/content-exclusion), and doesn't apply to symbolic links or repositories on remote filesystems.
- **No air-gapped service (as of 2026-10-29).** Copilot is GitHub-hosted. GitHub's offline options are client-side: Copilot CLI offline mode with a [local bring-your-own-key model](https://docs.github.com/en/copilot/how-tos/copilot-cli/set-up-copilot-cli/authenticate-copilot-cli) such as one [served by Ollama](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-llm-models), and, in public preview, local models in the [Copilot app](https://docs.github.com/en/copilot/how-tos/github-copilot-app/add-llm-models) on Windows PCs with an NVIDIA GPU.

## Common Questions

- **Can our developers keep using Copilot in Coder workspaces?** Yes. Copilot CLI installs through the [Copilot CLI module](https://registry.coder.com/modules/coder-labs/copilot). In VS Code connected to a workspace through the Coder extension, the [Copilot extension runs inside the workspace](https://coder.com/docs/ai-coder/ai-gateway/clients/copilot#coder-remote-extension), and VS Code agents can run [on a remote machine over SSH](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-in-ides).
- **Can Coder audit and govern Copilot usage?** Yes, with Premium. AI Gateway audits Copilot's model requests through [AI Gateway Proxy](https://coder.com/docs/ai-coder/ai-gateway/clients/copilot) for clients configured to use the proxy. Users still sign in to GitHub, because Copilot uses per-user tokens tied to GitHub accounts.
- **Can Coder Agents use our Copilot subscription for models?** No. Coder Agents [doesn't support Copilot as a model provider](https://coder.com/docs/ai-coder/agents/models). Coder Agents uses providers such as Anthropic, OpenAI, Google, Azure, AWS Bedrock, or OpenAI-compatible endpoints ([Coder Agents docs](https://coder.com/docs/ai-coder/agents)).
- **How does Copilot cloud agent differ from Coder Agents?** The difference is where it runs. Copilot cloud agent is orchestrated on GitHub and runs in [GitHub-managed sandboxes by default, or on Actions runners or a registered custom environment](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github). Coder Agents runs in the customer's Coder deployment, on its own network, including air-gapped with a self-hosted model endpoint ([Coder Agents docs](https://coder.com/docs/ai-coder/agents), [Coder Docs](https://coder.com/docs/install/prepare/airgap)). See also the [Coder Agents FAQ](../products/coder-agents/faq.md#16-competitive-landscape-vs-code-agents-and-github-copilot).
- **We use GitHub Enterprise Server or GitLab. Does Copilot work for us?** Copilot is [not currently available for GitHub Enterprise Server](https://docs.github.com/en/copilot/get-started/plans), and cloud agent [only works with GitHub-hosted repositories](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github). Coder works with [GitHub, GitLab, Bitbucket, and Azure DevOps](https://coder.com/docs/admin/external-auth).
- **Do we have to choose between Copilot and Coder?** No. Most teams use Copilot as a client inside Coder workspaces. The choice is only between Copilot cloud agent and Coder Agents for where background agents run, and teams can use both.
- **Which is cheaper?** It depends on usage. Copilot charges per seat, with or without included AI Credits, plus metered usage. With Coder, the customer pays its own model providers and compute, plus a Coder Premium license if needed, or AI Premium to run more than five Coder Agents at once ([Coder pricing](https://coder.com/pricing)). See Pricing and Packaging below.

## When GitHub Copilot Alone Is Enough

- **GitHub Enterprise Cloud organizations without self-hosting requirements.** Teams whose code is on GitHub and that accept [GitHub-hosted agent orchestration and execution](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github) get completions, chat, agents, and code review in one product.
- **Individual developers and small teams.** Developers who want an assistant in their IDE, with [Free, Pro, Pro+, and Max plans](https://github.com/features/copilot/plans), and no platform team.
- **Organizations without platform engineering capacity.** Teams that don't want to operate infrastructure or maintain Terraform templates.

## Pricing and Packaging

- **Copilot for organizations.** Copilot Business is $19 per granted seat per month with 1,900 AI Credits per user, and Copilot Enterprise is $39 per granted seat per month with 3,900 credits per user ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)). Credits are pooled, and usage beyond the pool is $0.01 per credit, with tokens priced by model ([GitHub billing docs](https://docs.github.com/en/copilot/concepts/billing-and-usage/organizations-and-enterprises/billing)). Inline suggestions don't consume credits. Copilot code review uses AI Credits and GitHub Actions minutes ([GitHub models and pricing](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing)).
- **Copilot access.** Since October 28, 2026, GitHub Enterprise Cloud customers working with a GitHub or Microsoft account team can get Copilot included for every GitHub Enterprise licensed user, with [no per-seat AI Credits, so usage is metered from the first request](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot/). Users without a GitHub Enterprise license get the same access through Copilot Standalone at $10 per user per month. Self-serve availability is coming in stages ([GitHub Changelog](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot/)), and Copilot access can't coexist with Copilot Business or Copilot Enterprise seats in the same enterprise ([GitHub Docs](https://docs.github.com/en/copilot/get-started/plans)).
- **Copilot for individuals.** Free, Pro at $10 per month, Pro+ at $39 per month, and Max at $100 per month, with different credit allotments ([GitHub plans](https://github.com/features/copilot/plans)).
- **Cloud agent compute.** Cloud sandbox usage is billed starting November 2026 and draws from the included GitHub Actions entitlement ([GitHub Changelog](https://github.blog/changelog/2026-10-28-work-from-anywhere-with-a-new-connected-copilot-cloud-experience/)).
- **Coder.** Coder Community is free and open source. Premium includes AI Governance, including AI Gateway ([Coder Docs](https://coder.com/docs/ai-coder/ai-governance)). Community and Premium cap Coder Agents at 5 concurrent agents, and AI Premium removes the cap. Coder does not publish a Premium price ([Coder pricing](https://coder.com/pricing)). See [Packaging](../company/packaging.md) for the narrative. Model usage and compute are billed by the customer's own providers.
