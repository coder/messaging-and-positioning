## One-Line Positioning

Claude Code is the coding agent developers use, and Coder is the self-hosted infrastructure where that agent runs, reaches internal systems, and is governed, whether Claude Code is launched inside a workspace or from Anthropic's cloud through [Agent Relay](../products/coder-agent-relay/claude-code-faq.md).

## Strategic Themes and Patterns

- **Relationship.** Complementary. Claude Code is an agentic coding tool that runs in the terminal, IDE, desktop app, and browser ([Claude Code overview](https://code.claude.com/docs/en/overview)), and Coder ships a [Claude Code module](https://registry.coder.com/modules/coder/claude-code) that installs and configures it inside Coder workspaces ([Coder docs](https://coder.com/docs/ai-coder)).
- **Formal integration.** Coder and Anthropic announced Claude Code support in Coder Agent Relay on September 15, 2026, built on Claude Code's publicly available self-hosted environments ([Coder announcement](https://coder.com/blog/agent-relay-claude-code-agentic-development)). Anthropic keeps orchestration and inference, and Coder provides the execution environment ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)).
- **Where the products overlap.** Two parts of Claude Code touch the execution layer Coder provides. Anthropic-hosted cloud sessions run on Anthropic-managed infrastructure ([Anthropic](https://claude.com/blog/claude-code-on-the-web)), and Anthropic's self-hosted environments let customers run their own runners ([Claude Code docs](https://code.claude.com/docs/en/self-hosted-environments)). Neither provides full development environment provisioning, and Coder's Agent Relay integration is built on the self-hosted runner rather than replacing it.
- **Choice, Control, Consistency.** This is not a substitution decision, so the tradeoff lens applies only partially. Standardizing on Claude Code alone narrows model Choice, since Anthropic does not support routing Claude Code to non-Claude models through any gateway ([Claude Code docs](https://code.claude.com/docs/en/llm-gateway)). Coder is model- and agent-agnostic and supports Claude Code alongside other harnesses and Coder Agents ([Why Coder](../company/why-coder.md), [Coder docs](https://coder.com/docs/ai-coder)).
- **How they work together.** In a workspace, a template admin adds the Claude Code module, optionally routes Claude Code through Coder AI Gateway, and wraps it with Agent Firewall ([AI Gateway client docs](https://coder.com/docs/ai-coder/ai-gateway/clients/claude-code), [Agent Firewall docs](https://coder.com/docs/ai-coder/agent-firewall)). For cloud sessions, Agent Relay claims each Claude Code session, provisions an ephemeral Coder workspace from a Terraform template, and deletes it when the runner exits ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)).

## Coder's Strengths Here

- **Complete environments, not only a runner.** Anthropic's runner executes Claude Code sessions, and Anthropic advises that a platform team own building the runner image, updating runners, and running the orchestrator ([Anthropic](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)). Coder adds declarative provisioning, networking, identity, governance, and lifecycle management around that runner ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)).
- **Session-scoped, ephemeral workspaces.** With Agent Relay, each Claude Code session gets its own workspace, provisioned on demand and deleted when the session ends ([coder.com/anthropic](https://coder.com/anthropic)).
- **Audit correlated to the session.** Every run produces an audit record of workspace provisioning and lifecycle tied to the Claude Code session and user it served ([Coder announcement](https://coder.com/blog/agent-relay-claude-code-agentic-development)).
- **Process-level network policy.** Agent Firewall restricts and audits what agent processes can reach, supports any terminal-based agent, and blocks domains and HTTP verbs to prevent exfiltration ([Agent Firewall docs](https://coder.com/docs/ai-coder/agent-firewall)).
- **Model governance across agents.** AI Gateway provides centralized authentication, audit trails of prompts and tool invocations, and policy enforcement against upstream LLM providers for Claude Code and other supported clients ([Coder docs](https://coder.com/docs/ai-coder), [AI Gateway client docs](https://coder.com/docs/ai-coder/ai-gateway/clients/claude-code)). Anthropic's Claude apps gateway covers SSO, model policy, and spend caps for Claude Code clients ([Claude Code docs](https://code.claude.com/docs/en/claude-apps-gateway)), so Coder's difference is governance that spans agents and pairs with workspace and network controls.
- **Provider flexibility inside the workspace.** The Claude Code module can target Coder AI Gateway, a customer's own Anthropic-compatible gateway, or Amazon Bedrock, Google Vertex AI, or Microsoft Foundry ([Coder Registry](https://registry.coder.com/modules/coder/claude-code)).
- **Offline-capable licensing.** Coder license keys validate locally without an outbound connection to Coder, so they work in air-gapped deployments ([Coder licensing docs](https://coder.com/docs/admin/licensing)).
- **One platform for many agents.** Customers can run Claude Code, Coder Agents, and other agents at the same time on the same governed infrastructure ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)).

## Claude Code Overview

- **What it is.** An agentic coding tool from Anthropic that reads a codebase, edits files, runs commands, and integrates with development tools ([Claude Code overview](https://code.claude.com/docs/en/overview)).
- **Surfaces.** Terminal, IDE extensions, a desktop app, and the web, with most surfaces requiring a Claude subscription or Anthropic Console account ([Claude Code overview](https://code.claude.com/docs/en/overview)).
- **Architecture, local.** Claude Code runs locally in the terminal and talks directly to model APIs without a backend server or remote code index ([Claude Code product page](https://claude.com/product/claude-code)).
- **Architecture, cloud sessions.** Cloud sessions run on Anthropic-managed cloud infrastructure and became generally available on September 23, 2026 for Pro, Max, and Team users and for Enterprise users with eligible seats ([Anthropic](https://claude.com/blog/claude-code-on-the-web)).
- **Architecture, self-hosted environments.** Customers deploy long-lived runners that pick up sessions, in either fixed or on-demand mode ([Anthropic](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)). Prompts, responses, and tool results still go to Anthropic for inference, and session transcripts are stored by Anthropic ([Anthropic](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)).
- **Inference providers.** Organizations can deploy through Anthropic directly or through a cloud provider, including Amazon Bedrock, Google Vertex AI, and Microsoft Foundry ([Claude Code enterprise deployment docs](https://code.claude.com/docs/en/third-party-integrations)).
- **Admin controls.** Team and Enterprise Owners can centrally configure Claude Code through server-managed settings, and endpoint-managed settings can be deployed through MDM or managed settings files ([Claude Code docs](https://code.claude.com/docs/en/server-managed-settings)).
- **Self-hosted gateway.** Anthropic's Claude apps gateway, released June 29, 2026, is a self-hosted service built into the `claude` binary that provides corporate SSO sign-in, model access and managed settings by IdP group, spend caps, OTLP usage telemetry, and routing to Amazon Bedrock, Google Cloud, Microsoft Foundry, or the Anthropic API ([Anthropic](https://claude.com/blog/introducing-the-claude-apps-gateway), [Claude Code docs](https://code.claude.com/docs/en/claude-apps-gateway)).
- **Target customer.** Individual developers through large enterprises, with Anthropic recommending Claude for Teams or Claude for Enterprise for most organizations ([Claude Code enterprise deployment docs](https://code.claude.com/docs/en/third-party-integrations)).
- **Deployment model.** SaaS for the product, orchestration, and cloud sessions, with the option of local execution or customer-operated self-hosted runners for session execution.

## Coder Overview for This Comparison

- **Coder Workspaces.** Self-hosted development environments defined as code with Terraform templates, running on infrastructure the customer controls ([Why Coder](../company/why-coder.md), [AWS Marketplace listing](https://aws.amazon.com/marketplace/pp/prodview-laypqph2nuvaq)).
- **Claude Code module.** Installs Claude Code in a workspace and can enable AI Gateway with one setting ([AI Gateway client docs](https://coder.com/docs/ai-coder/ai-gateway/clients/claude-code)).
- **AI Governance.** AI Gateway and Agent Firewall, providing model-level audit and policy plus process-level network policy inside workspaces ([Coder docs](https://coder.com/docs/ai-coder), [AI Governance message house](../products/coder-ai-governance/message-house.md)).
- **Agent Relay.** Connects a supported cloud-hosted agent provider's sessions to self-hosted Coder workspaces, with orchestration and inference staying cloud-hosted ([Coder docs](https://coder.com/docs/ai-coder)). Agent Relay launched with Cursor on September 2, 2026 and added Claude Code on September 15, 2026 ([DEVOPSdigest](https://www.devopsdigest.com/coder-agent-relay-supports-claude-code)).
- **Coder Agents.** Coder's native agent, whose agent loop runs in the Coder control plane on the customer's infrastructure so workspaces can be fully network isolated ([Coder docs](https://coder.com/docs/ai-coder)). This is the fully self-hosted option when inference and orchestration must also stay inside the perimeter ([Agent Relay message house](../products/coder-agent-relay/message-house.md)).

## Known Limitations in Claude Code's Approach

- **Orchestration and inference remain with Anthropic in cloud sessions (as of 2026-09-28).** Even with self-hosted environments, conversation content is sent to Anthropic for inference ([Anthropic](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)). This also bounds what Agent Relay can offer, and fully air-gapped requirements are not a fit for that architecture today ([Agent Relay message house](../products/coder-agent-relay/message-house.md)).
- **Self-hosted environments are a public beta for Team and Enterprise only (as of 2026-09-28).** They are off by default and not available to organizations using ZDR ([Anthropic](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)).
- **Customers operate the runner fleet themselves (as of 2026-09-28).** Anthropic advises that a platform or developer productivity team own the runner image, runner updates, and the on-demand orchestrator ([Anthropic](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)).
- **Runner host platform (as of 2026-09-28).** Runners need a Linux or macOS host or container, and Windows isn't supported as a runner host ([Claude Code docs](https://code.claude.com/docs/en/self-hosted-environments-quickstart)).
- **Cloud sessions and source hosting (as of 2026-09-28).** Cloud sessions require GitHub for repository cloning and pull request creation, with GitHub Enterprise Server supported on Team and Enterprise plans, and other Git hosts can only be sent as a local bundle that the session can't push back to ([Claude Code docs](https://code.claude.com/docs/en/claude-code-on-the-web)). Self-hosted environments also check out repositories from GitHub ([Claude Code docs](https://code.claude.com/docs/en/self-hosted-environments)).
- **Claude models only (as of 2026-09-28).** Anthropic does not support routing Claude Code to non-Claude models through any gateway ([Claude Code docs](https://code.claude.com/docs/en/llm-gateway)).
- **Some traffic bypasses a model gateway (as of 2026-09-28).** Claude Code sends version checks and downloads directly to Anthropic, separate from the gateway path, so egress policy needs to account for it ([Claude Code docs](https://code.claude.com/docs/en/gateways)). Coder's Agent Firewall documentation lists the Anthropic domains a Claude Code policy must allow ([Agent Firewall docs](https://coder.com/docs/ai-coder/agent-firewall)).
- **Endpoint policy does not reach Anthropic-hosted cloud sessions (as of 2026-09-28).** Endpoint-managed settings don't apply there, so organizations need server-managed settings as well, while self-hosted sessions also read the managed settings file in the runner image ([Claude Code docs](https://code.claude.com/docs/en/server-managed-settings)).

## Common Questions

- **Does Coder replace Claude Code?** No. Claude Code provides the developer experience, agent workflows, orchestration, and inference, and Coder provides the environments where Claude Code agents do their work ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)).
- **Anthropic now offers self-hosted runners. Why use Coder?** A runner provides compute for an agent, and Coder provides complete, governed development environments around it with provisioning, networking, identity, observability, and lifecycle ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)). The Agent Relay integration itself runs Anthropic's runner inside Coder workspaces ([Coder announcement](https://coder.com/blog/agent-relay-claude-code-agentic-development)).
- **Does any code leave our network when Claude Code runs on Coder?** Tool calls execute inside the self-hosted workspace ([Coder announcement](https://coder.com/blog/agent-relay-claude-code-agentic-development)), but conversation content, including tool results that can contain code, is sent to Anthropic for inference ([Anthropic](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)). Evaluate specific data flows against Anthropic's documentation rather than assuming all data stays inside ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)).
- **Can we keep inference inside our own cloud account?** For Claude Code running inside a workspace, yes, through Bedrock, Vertex AI, or Foundry, which the Coder module supports ([Coder Registry](https://registry.coder.com/modules/coder/claude-code), [Claude Code enterprise deployment docs](https://code.claude.com/docs/en/third-party-integrations)). For Claude Code cloud sessions through Agent Relay, inference stays with Anthropic and Coder AI Gateway is not in the path ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)).
- **We need everything, including inference, inside the perimeter. What fits?** Agent Relay is not a fit for that requirement today ([Agent Relay message house](../products/coder-agent-relay/message-house.md)). Coder Agents runs its agent loop in the self-hosted Coder control plane ([Coder docs](https://coder.com/docs/ai-coder)), and Claude Code in a workspace can use a customer-controlled inference endpoint ([Coder Registry](https://registry.coder.com/modules/coder/claude-code)).
- **Can developers use Claude Code and other agents at the same time?** Yes. Coder provides a common infrastructure layer rather than requiring one agent harness ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)).
- **Is Agent Relay for Claude Code available now?** It is in early access with select design partners, with documentation at coder.com/anthropic ([GlobeNewswire](https://www.globenewswire.com/news-release/2026/09/15/3362210/0/en/coder-brings-claude-code-to-agent-relay-unlocking-agentic-development-for-the-world-s-most-regulated-enterprises.html)). Coder's FAQ describes Agent Relay as in early access, in closed preview with design partners ([Agent Relay for Claude FAQ](../products/coder-agent-relay/claude-code-faq.md)).
- **Does Claude Code in Coder still need a Claude subscription?** With Agent Relay, Anthropic continues to handle billing ([Coder announcement](https://coder.com/blog/agent-relay-claude-code-agentic-development)). Inside a workspace, Claude Code can authenticate through AI Gateway with a Coder token, a personal Anthropic key, or a cloud provider backend ([AI Gateway client docs](https://coder.com/docs/ai-coder/ai-gateway/clients/claude-code), [Coder Registry](https://registry.coder.com/modules/coder/claude-code)).

## Pricing and Packaging

- **Claude Code is included in paid Claude plans.** Claude Code shares the same usage limits as the rest of the plan ([Claude pricing](https://claude.com/pricing)).
- **Claude Enterprise.** Priced at $20 per seat per month plus usage billed at API rates ([Claude pricing](https://claude.com/pricing)), with the seat fee covering access only ([Claude Help Center](https://support.claude.com/en/articles/9797531-what-is-the-enterprise-plan)).
- **Claude Team.** Premium seats include 6.25x the Pro plan's per-session usage allowance ([Claude Help Center](https://support.claude.com/en/articles/9266767-what-is-the-team-plan)). Secondary sources report $20 per Standard seat and $100 per Premium seat on annual billing ([Tygart Media](https://tygartmedia.com/claude-team-pricing-2026-standard-premium-seats/)), and they disagree on the minimum seat count.
- **Self-hosted environments are not priced separately in the sources reviewed.** They require a Team or Enterprise plan ([Anthropic](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)), and the customer pays for its own runner compute.
- **Coder.** Current tiers and prices are at [coder.com/pricing](https://coder.com/pricing); see [Packaging](../company/packaging.md) for the narrative. AI Governance (AI Gateway and Agent Firewall) is included with a Premium license, not sold as a separate add-on ([AI Governance message house](../products/coder-ai-governance/message-house.md), [Packaging](../company/packaging.md)).
- **Two bills.** Customers running Claude Code on Coder pay Anthropic (or their cloud provider) for Claude Code usage and Coder for the infrastructure layer.
