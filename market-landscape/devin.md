*Devin is built by Cognition (formerly Cognition Labs). Devin Desktop is the editor formerly called Windsurf ([Continuum](https://continuumcode.ai/guides/devin-pricing/), [Wikipedia](https://en.wikipedia.org/wiki/Cognition_AI)).*

## One-Line Positioning

Devin is an autonomous coding agent whose reasoning layer always runs in Cognition's cloud, while Coder runs the agent loop, the execution environments, and optionally model inference on infrastructure the customer owns and operates.

## Strategic Themes and Patterns

- **Relationship.** Competitive. Devin provides its own orchestration (the "brain") and its own execution environments ("Devboxes"), and Cognition sells it to the same enterprise buyer deciding where coding agents run ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview), [AWS Marketplace listing](https://aws.amazon.com/marketplace/pp/prodview-yt3ntkdpdjdgm)). Coder Agents targets the same decision with a fully self-hosted agent ([Coder Agents docs](https://coder.com/docs/ai-coder/agents)).
- **Choice, Control, Consistency.** The main tradeoff is Control. In every documented Devin enterprise model, the brain resides in Cognition's cloud, and even the dedicated option is hosted by Cognition in a single-tenant VPC ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)). A secondary tradeoff is Choice. Devin offers several frontier and in-house models, but secondary sources quoting Cognition's enterprise FAQ report no support for third-party LLM API keys or custom endpoints in the commercial product ([Continuum](https://continuumcode.ai/guides/continuum-in-devin/), [innFactory](https://innfactory.ai/en/ai-harness/devin/)). See [Coder Message House](../company/message-house.md).
- **Lock-in risk.** Adopting Devin ties agent orchestration, session history, and model routing to a vendor-operated service. Changing course later means moving those workflows to a different platform, not reconfiguring infrastructure the organization already runs. This is an inference from the architecture described above.
- **Build versus buy.** For organizations that require the agent loop itself to stay in-perimeter, the realistic alternative to Coder is building a self-hosted agent platform in-house, consistent with [Why Coder](../company/why-coder.md). Devin's Outposts does not change this, since planning and inference stay in Cognition's cloud ([Devin Outposts docs](https://docs.devin.ai/cloud/outposts/overview)).
- **Where Devin is sufficient on its own.** Organizations comfortable with vendor-hosted orchestration and whose repositories are reachable from Cognition's cloud can adopt Devin quickly. Cognition states Enterprise Cloud deployment can be completed within minutes ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)).

## Coder's Strengths Here

- **Agent loop runs self-hosted.** Coder Agents has no SaaS or managed component. The agent loop, chat history, and tool execution run within the customer's Coder deployment ([Coder Agents docs](https://coder.com/docs/ai-coder/agents)).
- **Air-gapped operation for the whole agent stack.** Coder documents that all Coder features are supported in air-gapped and offline deployments, and Coder Agents supports air-gapped deployments with self-hosted models ([Coder air-gap docs](https://coder.com/docs/install/airgap), [Coder 2.33 changelog](https://coder.com/changelog/coder-2-33)).
- **Open model access.** Administrators configure Anthropic, OpenAI, Google, Azure, AWS Bedrock, or any OpenAI-compatible endpoint, including self-hosted models and internal gateways ([Coder Agents docs](https://coder.com/docs/ai-coder/agents), [Coder Agents models docs](https://coder.com/docs/ai-coder/agents/models)).
- **Same infrastructure for people and agents.** Agent sessions run in Terraform-defined Coder workspaces, the same templates, identity provider, and controls platform teams already use for developers ([Coder Agents message house](../products/coder-agents/message-house.md), [Coder Workspaces](https://coder.com/solutions/workspaces)).
- **No LLM credentials in workspaces.** Model credentials stay in the control plane, and workspaces need no outbound access to LLM providers ([Coder Agents docs](https://coder.com/docs/ai-coder/agents), [Coder Agents message house](../products/coder-agents/message-house.md)).
- **Cloud-hosted agents are still an option.** For customers who accept a cloud-hosted agent, Agent Relay connects agents like Cursor to self-hosted Coder workspaces ([Coder Agents GA blog](https://coder.com/blog/coder-agents-ga)).

## Devin Overview

- **What it is.** An autonomous AI software engineer that plans, writes, tests, and ships code. Cognition offers it through Devin Cloud, Devin Desktop, Devin CLI, and Devin Review ([AWS Marketplace listing](https://aws.amazon.com/marketplace/pp/prodview-yt3ntkdpdjdgm)).
- **Architecture.** Two components. The brain is a stateless cloud service that always resides in Cognition's cloud. The Devbox is the virtual environment where Devin executes code ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)).
- **Target customer.** Enterprises and public sector. Cognition lists financial services, technology, healthcare, and defense ([AWS Marketplace listing](https://aws.amazon.com/marketplace/pp/prodview-yt3ntkdpdjdgm)).
- **Deployment model: Enterprise Cloud.** Brain and Devbox both run in Cognition's multi-tenant cloud, with an isolated machine per session. Recommended when SCM and artifact stores are public or support IP allowlisting ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)).
- **Deployment model: Customer Dedicated Deployment (Devin's VPC option).** Cognition hosts Devin in an auto-scaling, customer-isolated environment within a single-tenant VPC. The customer's VPC connects over AWS PrivateLink or an IPSec tunnel, and Cognition manages the infrastructure on the customer's behalf ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)). Cognition's VPC docs describe this as hosted in Cognition's tenant, with customer data encrypted using a custom KMS key and isolated brain containers per session ([Devin VPC overview](https://docs.devin.ai/enterprise/vpc/overview)). Cognition's marketing page describes Devboxes as "deployed within your Virtual Private Cloud," which reads differently from the docs; this page follows the docs and flags the conflict below.
- **Deployment model: Outposts (alpha).** Devin sessions run on customer-operated machines such as VMs, Kubernetes clusters, or a Mac mini. Inference and planning continue in Devin's cloud ([Devin Outposts docs](https://docs.devin.ai/cloud/outposts/overview)). It launched in alpha on July 21, 2026 ([daily.dev](https://daily.dev/posts/devin-outposts-lets-you-run-devin-sessions-on-your-own-machines-fmxetakxg)).
- **Deployment model: Federal.** The federal deployment runs on AWS GovCloud ([Devin federal docs](https://docs.devin.ai/federal/introduction)). As of July 2026, the full platform including Devin Cloud is FedRAMP High In-Process, while Devin Desktop and CLI are FedRAMP High Authorized ([Cognition blog](https://cognition.com/blog/devin-fedramp-high-in-process)).

## Coder Overview for This Comparison

- **Coder Agents.** A native coding agent written in Go that runs the agent loop in the Coder control plane and works with any configured LLM provider ([Coder Agents docs](https://coder.com/docs/ai-coder/agents)). It is generally available ([Coder Agents GA blog](https://coder.com/blog/coder-agents-ga)).
- **Coder Workspaces.** Self-hosted, Terraform-defined environments on any cloud or fully air-gapped on-premises, used by both developers and agents ([Coder Workspaces](https://coder.com/solutions/workspaces)).
- **AI Governance.** AI Gateway records prompts, token usage, and tool invocations with per-user attribution, and administrators control models centrally ([Coder Agents message house](../products/coder-agents/message-house.md), [Coder Agents models docs](https://coder.com/docs/ai-coder/agents/models)).
- **Deployment surface.** Coder Agents runs inside a customer VPC, on-prem, or in an air-gapped enclave ([Coder Agents solution page](https://coder.com/solutions/agents)).

## Where Devin Is Strong or Coder Has a Gap

- **Managed operations.** Cognition runs the infrastructure in both hosted models, so customers do not operate a control plane ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)). Coder is self-hosted, and at least one public reviewer cites operational overhead for teams without dedicated DevOps ([G2](https://www.g2.com/products/coder/pricing)).
- **Federal authorization path.** Cognition lists FedRAMP High authorization for Devin Desktop and CLI and IL4, IL5, and IL6 compliance, and is pursuing FedRAMP High for Devin Cloud ([Cognition blog](https://cognition.com/blog/devin-fedramp-high-in-process), [FedRAMP Marketplace](https://www.fedramp.gov/marketplace/products/FR2627211780/)).
- **Hands-on deployment services.** Enterprise includes a dedicated account team and an assigned Forward Deployed Engineer ([Devin Enterprise](https://devin.ai/enterprise)). For government, Cognition also offers firm-fixed-price delivery of outcomes ([Devin federal docs](https://docs.devin.ai/federal/introduction)).
- **Proprietary models and a broad product line.** Cognition trains its own SWE models alongside frontier models and pairs the cloud agent with an IDE, CLI, and code review product ([Cognition blog](https://cognition.com/blog), [AWS Marketplace listing](https://aws.amazon.com/marketplace/pp/prodview-yt3ntkdpdjdgm)).
- **Self-serve entry point.** Devin publishes self-serve plans starting at $20 per month ([Devin pricing](https://devin.ai/pricing)). Coder's paid tiers are sales-led ([Coder pricing](https://coder.com/pricing)).
- **On-prem and air-gapped CLI and editor.** Cognition's government page documents on-prem and air-gapped operation for the Devin CLI and desktop editor running on customer-approved models ([Devin Government](https://devin.ai/government)). Coder's own message houses previously described Devin as having no documented air-gapped option at all; that was a blanket claim that didn't account for this CLI and editor path, and has been corrected.

## Known Limitations in Devin's Approach

- **Reasoning layer is always vendor-hosted (as of 2026-09-28).** Cognition documents that the brain always resides in Cognition's cloud, including in Customer Dedicated Deployment and Outposts ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview), [Devin Outposts docs](https://docs.devin.ai/cloud/outposts/overview)).
- **The VPC option is hosted by Cognition (as of 2026-09-28).** The dedicated deployment is a single-tenant VPC that Cognition hosts and manages, connected to the customer's network by PrivateLink or IPSec, rather than a VPC the customer owns ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview), [Devin VPC overview](https://docs.devin.ai/enterprise/vpc/overview)). Cognition's marketing page states that Devboxes are "deployed within your Virtual Private Cloud," which reads differently from the docs ([Devin Enterprise](https://devin.ai/enterprise)). This page follows the more specific docs language; buyers should confirm directly with Cognition.
- **Outposts shifts operations to the customer (as of 2026-09-28).** Cognition states Outposts requires teams to secure and operate their own VMs at scale, and recommends the Dedicated Tenant for security-conscious customers ([Devin Outposts docs](https://docs.devin.ai/cloud/outposts/overview)).
- **Browser access to a Cognition domain (as of 2026-09-28).** In dedicated deployments, user workstations must reach `*.devinapps.com` over HTTPS for the IDE and browser viewer ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)).
- **Air-gapped support is scoped to specific surfaces (as of 2026-09-28).** Cognition's government page lists on-prem and air-gapped operation for the CLI and IDE, running on customer-approved model endpoints ([Devin Government](https://devin.ai/government)). It does not document an air-gapped option for the Devin Cloud agent, whose brain stays in Cognition's cloud.
- **Model endpoints (as of 2026-09-28; sources conflict).** Secondary sources quote Cognition's enterprise FAQ as saying Devin does not currently support third-party LLM API keys ([Continuum](https://continuumcode.ai/guides/continuum-in-devin/), [innFactory](https://innfactory.ai/en/ai-harness/devin/)). Cognition's government page refers to customer-approved model endpoints ([Devin Government](https://devin.ai/government)). We could not access Cognition's enterprise FAQ directly to confirm its exact scope, so both statements are reported here rather than resolved.

## Common Questions

- **Doesn't Devin run in our VPC?** Devin's dedicated option is a single-tenant VPC that Cognition hosts and manages, connected to your network by PrivateLink or IPSec, and the brain stays in Cognition's cloud, per Cognition's docs ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview), [Devin VPC overview](https://docs.devin.ai/enterprise/vpc/overview)). Cognition's own marketing page describes Devboxes as deployed "within your" VPC, which conflicts with that docs language ([Devin Enterprise](https://devin.ai/enterprise)); confirm directly with Cognition before relying on either description. Coder Agents runs the agent loop in your own VPC, on-prem, or air-gapped ([Coder Agents solution page](https://coder.com/solutions/agents)).
- **Doesn't Devin Outposts close the gap?** Outposts moves command execution, file edits, and repository access onto your machines, but inference and planning continue in Devin's cloud ([Devin Outposts docs](https://docs.devin.ai/cloud/outposts/overview)). With Coder Agents, the agent loop runs in your control plane and inference can use self-hosted models ([Coder 2.33 changelog](https://coder.com/changelog/coder-2-33)).
- **Can we use our own models?** Coder Agents connects to any configured provider, including Bedrock, Azure OpenAI, and OpenAI-compatible self-hosted endpoints ([Coder Agents models docs](https://coder.com/docs/ai-coder/agents/models)). Devin routes across the models it offers, and public sources disagree on whether custom endpoints are supported: Cognition's government page refers to customer-approved model endpoints, while secondary sources quoting Cognition's enterprise FAQ say third-party API keys aren't supported ([Devin Government](https://devin.ai/government), [Continuum](https://continuumcode.ai/guides/continuum-in-devin/)).
- **Does Devin support air-gapped deployment?** Partly. Cognition documents on-prem and air-gapped operation for the Devin CLI and desktop editor ([Devin Government](https://devin.ai/government)), but the Devin Cloud agent's reasoning layer always runs in Cognition's cloud with no documented air-gapped path ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)). Coder Agents supports air-gapped operation for the full agent loop, including inference with self-hosted models ([Coder air-gap docs](https://coder.com/docs/install/airgap), [Coder 2.33 changelog](https://coder.com/changelog/coder-2-33)).
- **Can Devin and Coder run together?** Neither company documents running a Devin Outposts worker in a Coder workspace. Outposts accepts customer-operated VMs and Kubernetes clusters ([Devin Outposts docs](https://docs.devin.ai/cloud/outposts/overview)), so it may be possible for a Coder workspace to act as an Outposts machine, but this is an unverified inference, not a documented capability. Developers can use any IDE against Coder workspaces today ([Coder Workspaces](https://coder.com/solutions/workspaces)).

## When Devin Alone Is Enough

- **Vendor-hosted orchestration is acceptable.** Organizations whose security review permits agent reasoning in a vendor cloud, and whose code hosts are public or IP-allowlisted, fit Enterprise Cloud ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)).
- **No platform team to operate infrastructure.** Teams that want a managed service over running their own control plane may prefer Devin's hosted models ([Devin enterprise deployment docs](https://docs.devin.ai/enterprise/deployment/overview)).
- **Individuals and small teams.** Self-serve plans cover individual developers and teams of up to 200 users ([Devin pricing](https://devin.ai/pricing)).

## Pricing and Packaging

- **Devin.** Free, Pro ($20 per month), Max ($200 per month), Teams ($80 per month plus $40 per full developer seat, up to 200 users), and Enterprise ("Let's talk"). Enterprise lists a dedicated deployment option and SAML/OIDC SSO ([Devin pricing](https://devin.ai/pricing)). Enterprise customers are billed in ACUs at the rate on their order form ([Fastio](https://fast.io/resources/devin-enterprise-guide/)).
- **Coder.** Community is free. Premium and AI Premium are sales-led. AI Premium removes the 5 concurrent Coder Agents cap on Community and Premium ([Coder pricing](https://coder.com/pricing)). Customers also run Coder on their own infrastructure, so compute and model costs are paid to their own providers ([AWS Marketplace, Coder Premium](https://aws.amazon.com/marketplace/pp/prodview-laypqph2nuvaq)). See [Packaging](../company/packaging.md).
