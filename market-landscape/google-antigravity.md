# Coder and Google Antigravity

| Date generated | 2026-10-20 |

*Antigravity CLI replaced Gemini CLI for individual users, and Gemini CLI stopped serving individual, Google AI Pro, and Google AI Ultra accounts on June 18, 2026 ([Google Developers Blog](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)). Google stopped selling new Gemini Code Assist Standard and Enterprise subscriptions on October 9, 2026 and points those customers to Antigravity in Gemini Enterprise ([Gemini Code Assist sunset](https://docs.cloud.google.com/gemini/docs/codeassist/sunset)).*

## One-Line Positioning

Antigravity is Google's agentic coding platform, where developers direct agents powered by Gemini and Claude models from a desktop app, CLI, IDE, or IDE extension, and Coder provides the self-hosted, governed workspaces that the Antigravity CLI, IDE, and IDE extensions connect to or run in, alongside Coder Agents and other agents.

## Strategic Themes and Patterns

- **Relationship.** Complementary. Coder documents Antigravity as a desktop IDE that connects to workspaces through the Coder extension ([Coder docs](https://coder.com/docs/user-guides/workspace-access/antigravity)), and the verified [Antigravity module](https://registry.coder.com/modules/coder/antigravity) adds a one-click button to open a workspace in it. Google built the Antigravity CLI to run in local shells, remote cloud environments, and SSH sessions ([Antigravity docs](https://antigravity.google/docs/overview)), so it can run in a workspace terminal. Coder's message house treats agentic IDEs as complements, not competitors ([Coder Agents message house](../products/coder-agents/message-house.md)).
- **Where the products overlap.** The Antigravity App runs agents on the user's own machine ([Antigravity](https://antigravity.google/product/)), and the CLI runs them wherever it's installed, including remote cloud environments and SSH sessions ([Antigravity docs](https://antigravity.google/docs/overview)). Google's managed option is the Antigravity agent on the Gemini API, which runs in a Google-hosted Linux sandbox and is in preview ([Gemini API docs](https://ai.google.dev/gemini-api/docs/antigravity-agent)). That hosted sandbox is the area adjacent to Coder workspaces and Coder Agents, whose agent loop runs in the customer's own Coder control plane ([Coder docs](https://coder.com/docs/ai-coder/agents)).
- **Choice, Control, Consistency.** Not a substitution decision. Antigravity serves Gemini and Claude models through Google, with availability that varies by plan and, in Gemini Enterprise, admin opt-in for Claude ([Antigravity docs](https://antigravity.google/docs/models), [Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools-settings)). The CLI accepts only `gemini` as a custom model provider ([Antigravity docs](https://antigravity.google/docs/install)). Coder adds Choice by running Antigravity next to Coder Agents, which supports Anthropic, OpenAI, Google, Azure OpenAI, AWS Bedrock, and OpenAI-compatible providers ([Coder docs](https://coder.com/docs/ai-coder/agents/models)).
- **How they work together.**
  - **IDE.** Developers open a workspace from the Antigravity IDE through the Coder extension or the module's one-click button ([Coder docs](https://coder.com/docs/user-guides/workspace-access/antigravity)).
  - **CLI.** Developers run the Antigravity CLI (`agy`) in a workspace. Over SSH it prints a sign-in URL to open in a local browser, and for headless use it accepts Application Default Credentials or a Gemini API key ([Antigravity docs](https://antigravity.google/docs/install)). Coder doesn't publish a registry module for the Antigravity CLI ([coder/registry](https://github.com/coder/registry)), so admins install it in the template like other workspace software.
  - **IDE extensions.** Gemini Enterprise developers can use Antigravity extensions instead of the standalone IDE ([Antigravity docs](https://antigravity.google/docs/enterprise)). Enterprise sign-in is generally available in the VS Code and Visual Studio extensions and in preview for JetBrains, Zed, and Xcode ([Antigravity docs](https://antigravity.google/docs/overview)). Antigravity for VS Code supports Remote-SSH workspaces ([Antigravity changelog](https://antigravity.google/docs/changelog)), and VS Code connects to Coder workspaces through the Coder Remote extension ([Coder docs](https://coder.com/docs/user-guides/workspace-access/vscode)). Coder's Antigravity docs cover the standalone IDE, not this combination.
  - **Division of labor.** Antigravity provides the agent harness, its permission settings, and Google-hosted inference. Coder provides the workspace, its network controls and access control, and audit logs for workspace and Agent Firewall activity ([AI Governance message house](../products/coder-ai-governance/message-house.md)).
- **Google Cloud context.** Google's preconfigured Cloud Workstations images also include Antigravity CLI ([Cloud Workstations release notes](https://cloud.google.com/workstations/docs/release-notes)). See [Coder and Google Cloud Workstations](./google-cloud-workstations.md).

## Coder's Strengths Here

- **A disposable place for autonomous runs.** Antigravity runs terminal commands on the machine where the agent runs, and commands outside its optional sandbox run "with full privileges" ([Antigravity docs](https://antigravity.google/docs/sandbox)). Google recommends unrestricted auto-approval only "in isolated development containers or disposable branches" ([Antigravity docs](https://antigravity.google/docs/enterprise)). Coder provides self-hosted, ephemeral workspaces defined in infrastructure-as-code templates ([AI Governance message house](../products/coder-ai-governance/message-house.md)), so the Antigravity CLI can run there instead of on a laptop.
- **HTTP and HTTPS egress allowlisting for the Antigravity CLI.** Agent Firewall restricts and audits the domains, HTTP methods, and paths that any terminal-based agent launched through it can reach over HTTP and HTTPS ([Coder docs](https://coder.com/docs/ai-coder/agent-firewall), [rules engine](https://coder.com/docs/ai-coder/agent-firewall/rules-engine)). Google publishes the Google API hostnames that Antigravity clients must reach on port 443 for Gemini Enterprise ([Antigravity docs](https://antigravity.google/docs/enterprise)), which gives that allowlist a starting point. Google doesn't publish an endpoint list for personal accounts, and API-key mode sends model requests to the Gemini API ([Antigravity docs](https://antigravity.google/docs/install)).
- **Environments that reach internal systems.** Workspaces run on infrastructure the customer controls and connect to private code, networks, and internal systems ([Why Coder](../company/why-coder.md)), so Antigravity agents running there work against those resources directly.
- **One-click IDE access.** The Antigravity module adds a button that opens the Antigravity IDE connected to a workspace ([Coder Registry](https://registry.coder.com/modules/coder/antigravity)).
- **Disconnected and air-gapped environments.** Coder supports fully air-gapped deployments ([Coder docs](https://coder.com/docs/install/prepare/airgap)), where Coder Agents can use self-hosted models ([Coder Agents message house](../products/coder-agents/message-house.md)). Antigravity's app, CLI, and IDE extensions need Google endpoints, either directly or through an Enterprise Gateway that forwards to Google Cloud ([Antigravity docs](https://antigravity.google/docs/enterprise), [Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools/deploy-enterprise-gateway)).

## Google Antigravity Overview

- **What it is.** An "advanced agentic coding platform and CLI" ([Antigravity](https://antigravity.google/llms.txt)) with five surfaces: the Antigravity App, the original Antigravity IDE, Antigravity CLI, IDE extensions, and a Python SDK. The IDE launched in public preview on November 18, 2025 ([Antigravity blog](https://antigravity.google/blog/introducing-google-antigravity/)). The App, CLI, and SDK (in preview) launched on May 19, 2026 ([Antigravity blog](https://antigravity.google/blog/introducing-google-antigravity-2/), [CLI blog](https://antigravity.google/blog/introducing-google-antigravity-cli/), [SDK blog](https://antigravity.google/blog/introducing-google-antigravity-sdk/)), and extensions for VS Code, Visual Studio, JetBrains, Zed, and Xcode followed in August 2026 ([Antigravity blog](https://antigravity.google/blog/antigravity-ide-extensions/)).
- **Architecture.** The App manages "multiple local agents in parallel" ([Antigravity](https://antigravity.google/product/)), and the App and CLI share one agent harness ([CLI blog](https://antigravity.google/blog/introducing-google-antigravity-cli/)). Inference runs on Google-hosted endpoints: Gemini Enterprise endpoints for enterprise users and the Gemini API for API-key users ([Antigravity docs](https://antigravity.google/docs/enterprise), [Antigravity docs](https://antigravity.google/docs/install)). Remote Control, in the App and CLI, gives browser access to agents that keep running on the host machine ([Antigravity docs](https://antigravity.google/docs/remote-control)).
- **Agent controls.** In the App and CLI, allow, ask, and deny rules govern file, URL, command, and MCP actions ([Antigravity docs](https://antigravity.google/docs/permissions)). An optional terminal sandbox uses OS-level isolation instead of VMs or Docker images. It's on by default in the App on macOS and Linux and off by default in the CLI and IDE ([Antigravity docs](https://antigravity.google/docs/sandbox), [Antigravity settings](https://antigravity.google/docs/settings)).
- **Models.** Gemini models and Anthropic Claude models served through Google, with availability that varies by plan and surface ([Antigravity docs](https://antigravity.google/docs/models)). Only the SDK documents local models ([Antigravity docs](https://antigravity.google/docs/sdk/local-models)).
- **Enterprise controls.** In Gemini Enterprise, admins set file access, terminal auto-execution, sandbox, browser, MCP allowlist, logging, and model policies in the Google Cloud console ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools-settings)). Developers sign in with Google Cloud SSO, Workforce Identity Federation, or Application Default Credentials ([Antigravity docs](https://antigravity.google/docs/enterprise)), or with a gateway-issued API key in Enterprise Gateway mode ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools/deploy-enterprise-gateway)). VPC Service Controls support is generally available ([Google Cloud docs](https://docs.cloud.google.com/vpc-service-controls/docs/supported-products)).
- **Enterprise Gateway.** Generally available since October 20, 2026, it routes model requests from the app, CLI, and the VS Code, Visual Studio, JetBrains, and Zed extensions through a customer-run gateway so organizations can inspect and audit model traffic and enforce egress policies, and the gateway forwards to Google Cloud ([Gemini Enterprise release notes](https://docs.cloud.google.com/gemini/enterprise/docs/release-notes), [Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools/deploy-enterprise-gateway)).
- **Data use.** Under the individual terms, Google uses interactions to improve its products and models, and people may review them unless the user changes a setting. Those terms don't apply to Gemini Enterprise users or Gemini Enterprise API keys ([Antigravity terms](https://antigravity.google/terms)), and Google says enterprise prompts, code, and transcripts aren't used to train models ([Antigravity docs](https://antigravity.google/docs/overview)).
- **Target customer.** Individual developers with personal Google Accounts ([Antigravity FAQ](https://antigravity.google/docs/faq)) and organizations on Gemini Enterprise Standard or Plus, including free trials, Standard Emerging Market, or Pay-as-you-go ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools-overview)), or on consumption-based API access ([Antigravity pricing](https://antigravity.google/pricing)).
- **Deployment model.** Client software on the machine where it's installed: the user's own machine for the App, and possibly a remote host for the CLI and VS Code Remote-SSH ([Antigravity docs](https://antigravity.google/docs/overview), [Antigravity changelog](https://antigravity.google/docs/changelog)), with Google-hosted inference. The managed Gemini API agent runs in a Google-hosted sandbox ([Gemini API docs](https://ai.google.dev/gemini-api/docs/antigravity-agent)).

## Coder Overview for This Comparison

- **Coder Workspaces.** Self-hosted development environments defined as code in Terraform templates on infrastructure the customer controls ([Why Coder](../company/why-coder.md), [Coder Agents message house](../products/coder-agents/message-house.md)). Antigravity connects to them through the Coder extension and the Antigravity module ([Coder docs](https://coder.com/docs/user-guides/workspace-access/antigravity)).
- **AI Governance.** AI Gateway for model-level audit and policy, and Agent Firewall for process-level HTTP and HTTPS egress allowlisting by domain, method, and path for terminal-based agents, included with Coder Premium ([Coder docs](https://coder.com/docs/ai-coder/ai-governance), [Packaging](../company/packaging.md)).
- **Coder Agents.** Coder's native agent, whose agent loop runs in the self-hosted Coder control plane and supports Gemini models through the Google AI API among other providers ([Coder docs](https://coder.com/docs/ai-coder/agents), [Coder docs](https://coder.com/docs/ai-coder/agents/models)).

## Known Limitations in Google Antigravity's Approach

- **The standalone IDE isn't supported for Gemini Enterprise.** Google supports enterprise integration for the App, CLI, and IDE extensions, and says the standalone Antigravity IDE "is not supported for enterprise deployments" ([Antigravity docs](https://antigravity.google/docs/enterprise)). The IDE also lacks Gemini 4 Argon, which the App, CLI, and IDE extensions offer ([Antigravity docs](https://antigravity.google/docs/models)). Coder's documented Antigravity integration and module target the standalone IDE ([Coder docs](https://coder.com/docs/user-guides/workspace-access/antigravity)).
- **No route through Coder AI Gateway.** Coder's AI Gateway docs list Antigravity and Gemini CLI as unsupported ([AI Gateway client docs](https://coder.com/docs/ai-coder/ai-gateway/clients#compatibility)). The Antigravity CLI's custom endpoint setting is for Gemini-compatible endpoints ([Antigravity docs](https://antigravity.google/docs/install)), and AI Gateway doesn't support the Gemini API. In Enterprise Gateway mode, Antigravity can send Gemini-protocol or OpenAI Chat Completions requests to a customer-run gateway, which Google requires to preserve Antigravity's attribution headers and forward to Gemini Enterprise Agent Platform with a service account ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools/deploy-enterprise-gateway)). Coder doesn't document AI Gateway in that role.
- **Google lists prompt injection as a known issue.** Google's known issues include data exfiltration through indirect prompt injection, and code execution through prompt injection when terminal auto-execution is set to Auto or Turbo ([Google Bug Hunters](https://bughunters.google.com/learn/invalid-reports/ai-products/antigravity-known-issues)). Google's enterprise docs pair Turbo with Always proceed as unrestricted auto-approval ([Antigravity docs](https://antigravity.google/docs/enterprise)). The Gemini Enterprise default for terminal auto-execution is Always proceed, and Google's best practices recommend Require review or Proceed in sandbox instead ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools-settings)).
- **No offline mode for the app, CLI, or IDE extensions.** With standard sign-in, clients must reach Google's global endpoints to load licenses and the model catalog, even for US or EU deployments ([Antigravity docs](https://antigravity.google/docs/enterprise)). With Enterprise Gateway, workstations connect to a customer-run gateway instead, but that gateway forwards inference to Google Cloud ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools/deploy-enterprise-gateway)). Only the SDK documents running local models without an internet connection ([Antigravity docs](https://antigravity.google/docs/sdk/local-models)).
- **Compliance scope.** Antigravity in Gemini Enterprise doesn't support FedRAMP Moderate or High, IL4, IL5, ITAR, ISO certifications including ISO 27001 and ISO 42001, SOC 1, 2, or 3, or Access Transparency ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/compliance-security-controls)). Antigravity in Gemini Enterprise is listed as a HIPAA BAA covered product ([Google Cloud HIPAA](https://cloud.google.com/security/compliance/hipaa)).

## Common Questions

- **Does Coder replace Antigravity?** No. Antigravity is where developers direct agents, and Coder provides the workspaces Antigravity connects to and where the Antigravity CLI can run ([Coder docs](https://coder.com/docs/user-guides/workspace-access/antigravity), [Antigravity docs](https://antigravity.google/docs/overview)).
- **How does Antigravity connect to a Coder workspace?** The Antigravity IDE connects through the Coder extension, from Antigravity's built-in marketplace or a downloaded `.vsix`, and admins can add the Antigravity module for a one-click button ([Coder docs](https://coder.com/docs/user-guides/workspace-access/antigravity)). Google built the Antigravity CLI for remote cloud environments and SSH sessions, so it runs in a workspace terminal ([Antigravity docs](https://antigravity.google/docs/overview)). Google documents the App working with local folders and, on Windows, WSL, and doesn't document it connecting to remote hosts ([Antigravity docs](https://antigravity.google/docs/getting-started), [Antigravity changelog](https://antigravity.google/docs/changelog)).
- **We're on Gemini Enterprise. Can our developers use the Antigravity IDE with Coder?** Google doesn't support the standalone IDE for enterprise deployments ([Antigravity docs](https://antigravity.google/docs/enterprise)). Use the CLI in a workspace, or Antigravity for VS Code, which supports Remote-SSH ([Antigravity changelog](https://antigravity.google/docs/changelog)). Coder's Antigravity docs cover the standalone IDE, so test the extension path during evaluation.
- **How does the Antigravity CLI sign in inside a workspace?** Over SSH, the CLI prints a sign-in URL to open in a local browser and accepts the resulting code. For headless use, it accepts Application Default Credentials for Gemini Enterprise or a Gemini API key, which sends requests straight to the Gemini API with no account session ([Antigravity docs](https://antigravity.google/docs/install)). With Enterprise Gateway, Google documents environment variables for remote development VMs and containers, for CLI 1.2.15 or later on Linux x86_64 or macOS arm64 ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools/connect-enterprise-gateway)). Interactive sign-in stores tokens in the OS keyring, which on Linux uses the Secret Service through D-Bus, so headless or SSH sessions need an active D-Bus session and keyring daemon ([Antigravity docs](https://antigravity.google/docs/cli/troubleshooting)). Under consumer plans, Google doesn't support wrapping `agy` inside third-party coding agents or applications ([Antigravity FAQ](https://antigravity.google/docs/faq)).
- **Do Coder's controls apply to Antigravity's agent?** Workspace-level network controls apply to agent activity running inside a workspace ([AI Governance message house](../products/coder-ai-governance/message-house.md)), and Agent Firewall applies to terminal-based agents launched through it, such as the Antigravity CLI ([Coder docs](https://coder.com/docs/ai-coder/agent-firewall)). Google doesn't document where the standalone IDE's agent or the VS Code extension's `agy` backend runs over SSH, and Coder doesn't document Agent Firewall coverage for IDE agents. For governed execution, run the Antigravity CLI in the workspace under Agent Firewall, or use Coder Agents.
- **Can Antigravity's model traffic go through Coder AI Gateway?** Not today. Coder's AI Gateway docs list Antigravity and Gemini CLI as unsupported ([AI Gateway client docs](https://coder.com/docs/ai-coder/ai-gateway/clients#compatibility)). Google's routing option is Antigravity Enterprise Gateway (see the next question), and Gemini Enterprise admins can also turn on prompt and response logging to Cloud Logging in their own project, which is off by default ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools-settings)). Gemini models used through Coder Agents do go through AI Gateway, which reaches Google through its OpenAI-compatible endpoint ([AI Governance message house](../products/coder-ai-governance/message-house.md), [Coder docs](https://coder.com/docs/ai-coder/agents/models), [AI Gateway provider docs](https://coder.com/docs/ai-coder/ai-gateway/providers)).
- **Antigravity now has an enterprise gateway. Is that the same as AI Gateway?** No. Antigravity Enterprise Gateway is a client routing mode: Antigravity sends model requests to a gateway the customer builds and runs, which forwards them to Gemini Enterprise Agent Platform with a service account. It covers Antigravity's app, CLI, and the VS Code, Visual Studio, JetBrains, and Zed extensions, not Xcode or Antigravity on the web ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/ai-developer-tools/deploy-enterprise-gateway)). Coder governs the environment where agents run and includes a gateway: AI Gateway covers Coder Agents and supported clients such as Claude Code and Codex, and Agent Firewall covers the HTTP and HTTPS egress of wrapped agent processes ([AI Governance message house](../products/coder-ai-governance/message-house.md)).
- **Can Antigravity run air-gapped or in FedRAMP or IL5 environments?** Not from Google's documentation. Its clients need Google endpoints, directly or through an Enterprise Gateway that forwards to Google Cloud, and Antigravity in Gemini Enterprise doesn't support FedRAMP Moderate or High, IL4, IL5, or ITAR ([Antigravity docs](https://antigravity.google/docs/enterprise), [Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/compliance-security-controls)). Coder supports fully air-gapped deployments, where Coder Agents can use self-hosted models ([Coder docs](https://coder.com/docs/install/prepare/airgap), [Coder Agents message house](../products/coder-agents/message-house.md)).
- **What should Gemini CLI and Gemini Code Assist customers know?** Gemini CLI remains available through Gemini Code Assist Standard or Enterprise licenses or paid Gemini and Gemini Enterprise Agent Platform API keys ([Google Developers Blog](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)). Existing Code Assist annual subscriptions renew until January 31, 2027 and monthly subscriptions until December 31, 2027 ([Gemini Code Assist sunset](https://docs.cloud.google.com/gemini/docs/codeassist/sunset)). Coder removed its deprecated Gemini CLI module (`coder-labs/gemini`) from the registry in July 2026, and published versions remain downloadable ([coder/registry](https://github.com/coder/registry/pull/1025)).
- **Can we run Antigravity and Coder Agents side by side?** Yes. Developers can use Antigravity against Coder workspaces while Coder Agents runs background work from the Coder control plane, including with Gemini models ([Coder docs](https://coder.com/docs/ai-coder/agents/models)).

## Pricing and Packaging

- **Antigravity for individuals.** A free tier labeled generally available, with "Basic weekly rate limits" ([Antigravity pricing](https://antigravity.google/pricing)). Higher limits come with Google AI Pro at $19.99 per month and Google AI Ultra at $99.99 or $199.99 per month in the US ([Google AI plans](https://gemini.google/subscriptions/)). Google doesn't publish numeric quotas ([Antigravity docs](https://antigravity.google/docs/plans)).
- **Antigravity for organizations.** Gemini Enterprise Standard and Plus start at $30 per seat per month, and Pay-as-you-go has a $0 seat fee with consumption pricing ([Antigravity pricing](https://antigravity.google/pricing)). Antigravity in Gemini Enterprise requires an invoiced Cloud Billing account and isn't included in the Business or Frontline editions ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/editions)). Standard and Plus seats include pooled per-user credits, and Claude models are pay-as-you-go only ([Gemini Enterprise docs](https://docs.cloud.google.com/gemini/enterprise/docs/quotas-and-overages)). Pricing is subject to change; consult the live pages.
- **Coder.** See [coder.com/pricing](https://coder.com/pricing) for current tiers and prices, and [Packaging](../company/packaging.md) for the reasoning behind them. AI Governance (AI Gateway and Agent Firewall) is included with Premium, not sold as a separate add-on ([Packaging](../company/packaging.md)). Community and Premium run up to five Coder Agents concurrently, and AI Premium removes the cap ([coder.com/pricing](https://coder.com/pricing)).
- **Combined cost.** A team using Antigravity on Coder pays for Antigravity through Google AI plans or Gemini Enterprise, the compute that runs its workspaces, and Coder Premium if it needs AI Governance or other Premium features, since the Community edition is free ([coder.com/pricing](https://coder.com/pricing)). This is inferred from the two pricing models, not a published bundle.
